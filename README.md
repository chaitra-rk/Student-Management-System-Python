# Student-Management-System-Python

A simple **Python + MySQL CRUD application** developed to practise database connectivity and SQL operations.

## Features
- Add new student records
- View all student records
- Search students by ID
- Update student details
- Delete student records

## Technologies Used
- Python
- MySQL
- MySQL Workbench

## Project Structure
```text
Student-Management-System/
│
├── db.py
├── add.py
├── view.py
├── search.py
├── update.py
├── delete.py
└── main.py
```

## How to Run
1. Install Python and MySQL.
2. Create the required database and `students1` table.
3. Configure your MySQL connection in `db.py`.
4. Run the application:

```bash
python main.py
```

## Learning Outcomes
- Understanding CRUD operations.
- Connecting Python with MySQL.
- Writing and executing SQL queries.
- Organising Python code into modules.

*This project was created as a hands-on learning exercise to understand Python database connectivity and SQL operations.*
